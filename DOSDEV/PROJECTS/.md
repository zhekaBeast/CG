# Техническое задание

## 1. Вариант выполнения

**ИВ3** — индивидуальное выполнение.

**Среда разработки и платформа:**
- язык программирования: Turbo Assembler (TASM);
- операционная система: DOS 6.xx (в том числе среда DosBox с соответствующей версией DOS);
- вывод графики: прерывания `int 10h`, графический режим VGA/EGA (основной режим — VGA 13h, 320×200, 256 цветов).

**Базовые рабочие задачи (обязательные):**
- ОЗ.Р1 — разработка программной логики реализации смены положения движущихся фигур;
- ОЗ.Р2 — разработка программной логики вывода изображения (кадра);
- ОЗ.Д1 — оформление и представление результатов.
  
**Дополнительные рабочие задачи:**
- ДЗ.А1 — использование равностороннего треугольника в качестве типа габаритов фигуры (без вращения), разработка алгоритма и программной реализации определения выхода за границы области движения;
- ДЗ.Б1 — дополнение движения фигуры постепенным вращением относительно точки центра, разработка алгоритма и программной реализации поворота точек относительно центра фигуры на заданный градус;
- ДЗ.В5 — замена равномерного прямолинейного движения фигуры движением с заданной изначальной скоростью (в результате однокранного приложения силы) с учётом силы тяготения (направлена вертикально вниз), при столкновении с границами области движения должен происходить «отскок» по закону отражения луча с приданием импульса (повторное приложение силы);
- ДЗ.Е3 — оптимизация отрисовки графического содержимого за счёт реализации схемы «двойной буферизации», с возможностью принудительной установки частоты кадров (FPS) и размера области вывода, с исследованием артефактов.

## 2. Общие требования к программному модулю

### 2.1 Основной рабочий цикл
Программный модуль должен:
- запускаться в среде DOS (или DosBox);
- переходить в основное рабочее состояние;
- реализовывать цикличный вывод динамически изменяющегося растрового изображения;
- обеспечивать штатное завершение работы с возвратом в DOS.

### 2.2 Содержимое отображаемой графики
- Отображаемое содержимое — динамически изменяющееся растровое изображение.
- Графические элементы — процедурные фигуры, отрисованные средствами растровой графики (контур + закраска).
- Движущаяся фигура — **равносторонний треугольник** (согласно ДЗ.А1).
- Фигура перемещается внутри ограниченной области (экран 320×200, режим VGA 13h).
- Перемещение реализуется согласно ДЗ.В5 (баллистика с гравитацией и отскоком).
- Дополнительно фигура постепенно вращается относительно своего центра (согласно ДЗ.Б1).

### 2.3 Способы и параметры вывода графики
- Вывод графики — только через прерывания `int 10h`, режим VGA/EGA.
- Отображение — непрерывное, с циклом отрисовки.
- Цикл отрисовки включает:
  - обновление параметров графического содержимого;
  - очистку области отрисовки;
  - вывод нового графического содержимого.
- Отрисовка ведётся в «задний буфер» с последующим переносом на экран (согласно ДЗ.Е3).

### 2.4 Взаимодействие с пользователем
- Минимальный набор: запуск приложения, переход в основное рабочее состояние, завершение работы.
- Дополнительно (по ДЗ.Е3): управление частотой кадров и размером области вывода.

## 3. Требования по базовым задачам

### 3.1 ОЗ.Р1 — Смена положения движущихся фигур

**Математический аппарат:**
- описание координат, габаритов и свойств единичной точки и сложной фигуры (равносторонний треугольник) в таблично-дискретном и аналитическом виде;
- математическая модель перемещения точки и фигуры согласно ДЗ.В5:
  - уравнение движения с начальной скоростью и ускорением свободного падения;
  - условие отскока от границ области движения по закону отражения луча;
  - правило придания импульса при отскоке;
- математическая модель определения выхода за границы области перемещения согласно ДЗ.А1:

### 4.3 ДЗ.В5 — Баллистическое движение с гравитацией и отскоком

**Требования:**
- заменить равномерное прямолинейное движение фигуры движением с заданной изначальной скоростью (в результате однократного приложения силы) с учётом силы тяготения (направлена вертикально вниз);
- при столкновении с границами области движения должен происходить «отскок» по закону отражения луча с приданием импульса (повторное приложение силы);
- разработать алгоритм и программную реализацию перемещения фигуры соответствующим образом;
- значения величины и направления изначальной скорости, а также масса и величина силы, прикладываемой при «отскоке», могут быть заданы пользователем либо занесены в программу изначально.

**Математический аппарат:**
- уравнение движения с начальной скоростью и ускорением свободного падения:
  - vₓ = v₀ₓ;
  - v_y = v₀_y + g·t;
  - x = x₀ + v₀ₓ·t;
  - y = y₀ + v₀_y·t + (g·t²)/2;
- закон отражения луча при столкновении с границей;
- правило придания импульса при отскоке.

**Алгоритмы:**
- алгоритм перемещения точки и фигуры по баллистической траектории;
- алгоритм определения выхода за границы области;
- алгоритм обработки отскока с приданием импульса.

**Программная логика:**
- реализация баллистического движения;
- реализация отскока и повторного придания импульса;
- хранение и обновление параметров скорости, массы, силы.

**Ограничение:**
- не допускается использование «готовых решений», предлагаемых ЯП, СРПО, подключаемыми библиотеками и т.д.

**Документирование:**
